# [작업 시작] · [작업 정리] 슬랙 초안

같은 기능을 두 사람이 만드는 일을 막고, 무엇이 끝났는지 팀이 한눈에 보게 하는 메시지다.
여러 팀 프로젝트(해커톤 · 교과 프로젝트 · 아카데미)에서 같은 형식으로 썼다.

## 철칙

- **초안만 만든다.** 슬랙 초안 기능(`slack_send_message_draft`)이나 텍스트로 보여 주고, 보내는 건 사용자가 한다.
- **키 · 비밀번호 · 토큰 · 서버 내부 주소는 절대 넣지 않는다.**
- **착수 전에 다른 사람의 오늘 [작업 시작]부터 읽는다.** 같은 일을 이미 누가 잡았으면 초안에 그 사실을 적고 사용자에게 먼저 알린다.

## 어디에

- 그날 첫 메시지는 **[작업 시작]** 새 글, 이후 **[작업 정리]**는 그 글의 스레드로 단다.
  스레드 위치를 모르면 채널을 읽어 오늘 내 [작업 시작] 글을 찾는다.
- 다른 사람 문서와 내용이 어긋난 걸 알릴 때는 팀 공용 채널에 따로.
- 채널 ID · 팀원 ID는 프로젝트 CLAUDE.md에 표로 적어 두고 읽는다(이 스킬에는 넣지 않는다).

## 멘션

초안에는 `<@U…>` 같은 ID가 아니라 **`@이름`으로** 쓴다. ID 형식은 초안에서 글자 그대로 보여서 사용자가 다시 고쳐야 한다.

## 먼저 모을 것

1. 오늘 머지된 PR · 열린 PR — `gh pr list -R <조직/저장소> --state all --limit 15` (저장소마다)
2. 노션 실험 기록 · 문서 버전 변경
3. 프로젝트 CLAUDE.md의 '다음 작업'

## 형식

```
[작업 정리] <한 줄 요약>

**<영역>** — 배포 / 데이터 / AI / 문서 등 영역별
• 한 일 — 결과 숫자 하나 + 쉬운 말 해석 (예: "상위 20% 적중 86% (무작위면 20%)")
• PR 번호 (#24), 다른 저장소면 "FE #4"

**다음에 할 일**
1. … (우선순위 순)

**확인 · 부탁**
• @이름 무엇을 언제까지 / 왜 필요한지

🔗 관련 노션 문서나 PR
```

- **[작업 시작]**은 「할 일 (순서대로)」 번호 목록 + 사람별 부탁 + "오늘은 N번까지".
- 말투는 해요체, 짧게. 전문 용어는 한 번 풀어 쓴다 (C-index → "무작위 0.5, 목표 0.65").
- **목표에 못 미친 것 · 바뀐 계획은 숨기지 말고** 이유와 함께 적는다.
- 슬랙 초안 도구는 굵게를 `**`로 받는다. 섹션 제목은 `**`, 문장 속 강조는 `*`.

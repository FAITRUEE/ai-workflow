■ 1단계 — Node.js 설치 (안 깔린 사람만)

nodejs.org 접속 → LTS 버튼 눌러서 설치
터미널(맥) 또는 PowerShell(윈도우)에서 아래 입력:

   node -v

버전 숫자가 뜨면 성공입니다. 이미 깔려있으면 넘어가세요.


■ 2단계 — 명령어 한 줄 실행

아래에서 본인 OS 것만 복사해서 터미널에 붙여넣으세요.
'받은토큰' 자리에 DM으로 받은 토큰을 그대로 붙여넣으면 됩니다.

윈도우:
   claude mcp add notion --scope user --env NOTION_TOKEN=받은토큰 -- cmd /c npx -y @notionhq/notion-mcp-server

맥:
   claude mcp add notion --scope user --env NOTION_TOKEN=받은토큰 -- npx -y @notionhq/notion-mcp-server


■ 3단계 — 확인

   claude mcp list

목록에 이렇게 나오면 끝입니다:
   notion: ... - ✅ Connected

Claude를 새 창(새 세션)으로 열고 "노션에서 <문서이름> 찾아줘" 해보세요.
※ 이미 열려있던 세션에는 안 붙습니다. 꼭 새로 여세요.

● "spawn npx ENOENT" 에러가 난다 (윈도우)
  → cmd /c 를 빼먹은 경우입니다. 2단계 명령어를 그대로 쓰세요.

● 데스크톱 채팅 앱에서도 쓰고 싶다
  → 설정 → 개발자 → 설정 편집 → claude_desktop_config.json 열고
    맨 앞 { 바로 다음에 아래를 넣으세요.

    "mcpServers": {
      "notion": {
        "command": "cmd",
        "args": ["/c", "npx", "-y", "@notionhq/notion-mcp-server"],
        "env": { "NOTION_TOKEN": "받은토큰" }
      }
    },

    맥은 "command": "npx" / "args": ["-y", "@notionhq/notion-mcp-server"] 로 바꾸세요.

● 설정을 저장했는데 자꾸 사라진다
  → 앱이 켜진 상태로 고치면 앱이 덮어씁니다. 완전 종료 → 수정 → 실행 순서로 하세요.

● 연결은 됐는데 특정 문서가 안 읽힌다
  → 그 페이지에 연결이 안 걸린 겁니다. 저한테 페이지 이름 알려주세요.

안 되면 저한테 DM 주세요.

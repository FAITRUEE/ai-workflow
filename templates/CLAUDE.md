## 확인 규칙

- "작동한다"고 적기 전에 그 경로를 실제로 통과시킨다 (`assumption-check` 스킬).
- 측정값은 **무엇부터 무엇까지 쟀는지** 먼저 고정한다.
- AI는 브랜치에서 작업하고 **PR까지만** 올린다. 병합 · 최종 결정은 사람이 한다.

## 작업 기록 규칙 (팀 합의)

| 어디에 | 무엇을 |
|---|---|
| 슬랙 | `[작업 시작]` / `[논의 요청] @멘션` / `[작업 정리]` + 노션 링크 |
| 노션 칸반 | 개인 작업 기록 (진행 / 막힌 점 / 다음 / 결과물) |
| PR 본문 | 무엇을 / 왜 / 어떻게 확인했나 / 버린 방안과 이유 |

- **착수 전에 슬랙의 다른 사람 `[작업 시작]`부터 확인한다.** 같은 기능을 두 사람이 만드는 일을 막는다.
- 슬랙 메시지는 AI가 초안을 쓰고, **보내기 전에 사람이 확인한다.**

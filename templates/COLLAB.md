# COLLAB.md — AI 두 개가 같이 일할 때

> 「눈치」(9일 · 4인 팀)에서 Claude와 Codex에게 영역을 나눠 맡기고, 둘이 서로 찾은 문제를 이 문서로 주고받게 한 양식.
> 두 AI 모두 작업 전에 이 파일을 읽고, 작업이 끝나면 자기 칸을 갱신한다.

## 역할

| AI | 맡는 저장소 · 영역 | 하지 않는 것 |
|---|---|---|
| **Claude** | `FE` — 3D 시뮬레이터 화면 | BE · AI 저장소 직접 수정 |
| **Codex** | `BE` · `AI` — 서버 · 모델 내보내기 · 배포 | FE 직접 수정 |
| **사람** | 방향 결정 · 라벨링 · **PR 병합** | — |

## 공통 규칙

1. 작업은 **브랜치 → 자체 검토 · 검증 → PR → 사람이 병합.** AI가 직접 병합하지 않는다.
2. 상대 영역에서 문제를 찾으면 **고치지 않고 아래 표에 적어 넘긴다.**
3. 작업마다 새 문서를 만들지 않고, 이 파일과 기존 문서만 갱신한다.
4. 팀원 작업 · 원본 데이터 · git에 안 올린 파일은 건드리지 않는다.
